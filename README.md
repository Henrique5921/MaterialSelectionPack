# Material Selection Pack
Projeto testando as várias formas de preenchimento de formulário.
## Resumo do Desenvolvimento
Qual o nome do componente Slider? Qual a variável responsável por armazenar o 
valor padrão do Slider? 
-> O nome é Slider. O valor padrão é armazenado pela variável _convidadosPadrao.
Porque em um dos botões um está marcado como “OutlinedButton” e o outro 
como “ElevatedButton”? Qual a diferença visual entre eles? Possuem parâmetros 
diferentes? Quais?
-> Têm funções diferentes. O primeiro tem borda, sendo mais secundário, enquanto o segundo tem aspecto elevado. Por isso os parametros são diferentes.
Qual a finalidade do método setState() dentro do RadioGroup?
-> Sinalizar que os dados foram alterados.
Explique para uma criança de 10 anos o que faz o método “.map” na lista de itens 
do dropdown.
-> Serve para selecionar e alterar o formato dos itens, quando for chamado.
Como é controlado as tags selecionadas do usuário do tipo Chip (FilterChip)?
-> São usadas para filtrar o conteúdo vísivel nas telas.
